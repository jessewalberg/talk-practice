# MetaToe Strategy

## Target problem

Friends who want a competitive head-to-head session don't have a digital option that feels polished and worth playing, so they default to pen and paper even when the rules are clear.

## Our approach

Win by leaning into a distinctive aesthetic that makes the session feel like an event — not a utility grid — so rivals choose MetaToe over paper.

## Who it's for

**Primary:** Friends with an ongoing rivalry (pass-and-play, same device) — they're hiring MetaToe to settle it in one decisive match.

## Key metrics

- **Match completion rate** — % of started games that reach a declared winner; measured in app analytics / session DB
- **Immediate rematch rate** — % of completed matches followed by a rematch in the same session; measured in app analytics / session DB
- **7-day rivalry return rate** — % of player pairs who start a new match within 7 days; measured in app analytics / session DB (local pair tracking for pass-and-play)

## Tracks

### Match presentation

Visual identity, motion, and feedback that make each move feel consequential.

_Why it serves the approach:_ The event feel is the core bet — presentation is how rivals experience "this is worth playing" vs. paper.

### Core rules engine

Ultimate tic tac toe rules, valid moves, win detection, and board state — correct and invisible when it works.

_Why it serves the approach:_ A polished session collapses if the game breaks trust; the engine stays out of the way so presentation carries the moment.

### Rivalry ritual

Pass-and-play flow, match start/finish framing, rematch prompts — the arc of one decisive match.

_Why it serves the approach:_ Rivals hire MetaToe to settle a score; ritual turns a grid into a bout with a clear beginning, climax, and outcome.
